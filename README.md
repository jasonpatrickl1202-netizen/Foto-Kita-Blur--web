# 📸 Foto-Kita-Blur--web

This repository contains a web-based application inspired by the trending **"Foto Kita Blur"** aesthetic. Built cleanly and simply using **HTML** (100%), this project allows users to easily upload their images and apply an artistic blur effect directly through their web browser.

## ✨ Core Features
* 🖼️ **Instant Photo Upload:** Easily choose and upload any image file from your local device storage.
* 🎛️ **Adjustable Blur Intensity:** Customize the level of blur to match the exact aesthetic you want.
* 💾 **Download Option:** Save your edited, blurry photo back to your device with optimal quality.
* ⚡ **Lightweight & Fast:** Runs entirely on the client-side without needing heavy backend server processing.

## 🛠️ Built With
* **HTML5:** Structure of the web application and layout elements.
* *(Optional for future updates)* **CSS3 & JavaScript:** For enhanced styling and image manipulation logic using Canvas API or CSS filters.

## 🚀 Getting Started (Local Setup)

To run this project locally on your machine, follow these simple steps:

1. **Clone the Repository:**
   ```bash
   git clone https://github.com
   ```
2. **Navigate to the Project Directory:**
   ```bash
   cd Foto-Kita-Blur--web
   ```
3. **Open the Application:**
   Simply double-click the `index.html` file to launch it instantly in your preferred web browser (Google Chrome, Firefox, Edge, Safari, etc.).
